Questions people ask

Why does the passenger screen ask for a language?

Each passenger picks their own language the first time they open their seat (English, Hindi, Tamil or Thai, each also written in English). The phone remembers it. If the passenger chose a language at check-in, the seat opens in it straight away. Crew always see Japanese and English.

What is the crew PIN?

A 6-digit code, like a door code. Passengers and crew share the same Wi-Fi, so the crew screens are locked. It is shown above (only on this laptop) and printed in the terminal when Auralink starts. Each device asks once, then stays unlocked for 24 hours.

Does it need the internet?

No. Speech to text, matching, fonts and every screen run on this laptop. Phones only need to reach the laptop over Wi-Fi. You can unplug the internet during the demo to prove it.

A phone cannot open the QR link

The phone must be on the same Wi-Fi as this laptop, and mobile data should be off or it may try the internet. Some guest Wi-Fi networks block devices from seeing each other: use a phone hotspot or your own router.

There's no screen at every seat — how does a passenger scan anything?

One shared code at the galley or on a seatback card opens /passenger with no seat baked in; the passenger taps their own seat on a plane-shaped map before anything connects. Per-seat QR codes (Seat QR cards) still work the same as before where you can print one per seat.

What do the colours on the crew's cabin map mean?

Red is urgent (e.g. a possible medical request); violet is an open request from a passenger with an accessibility need on file; amber is any other open request; dark grey is no open request. The crew tablet shows this key above its own cabin map too.

Does Auralink need to integrate with the airline's reservation system to know a seat?

No. Every boarding pass, paper or digital, already carries an IATA-standard barcode (BCBP) with the seat number in it. The seat gate's Scan boarding pass option just reads that barcode with the phone's camera, fully offline — no airline API, no partnership, no network call. Boarding pass simulator issues a real BCBP-format pass to test with, since nobody at a hackathon has a genuine one.
