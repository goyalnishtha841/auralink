Phone setup so the microphone works

This phone right now

Why this is needed

Phones only let a web page use the microphone if the page is secure (https). The hub makes its own certificate with mkcert, so each phone has to trust it once. Typing and pictures work without this; only voice needs it. Do this once per phone, before the demo.

The laptop has no certificate yet. On the laptop run scripts/setup_https.sh, then scripts/demo.sh, and reload this page.

  3. Download the certificate

    then tap Allow.

  4. Install it

    Open Settings → Profile Downloaded (near the top) → Install, enter your passcode.

  5. Trust it

    Settings → General → About → Certificate Trust Settings → turn on the switch for mkcert.

  6. Check

    Reload this page. "Secure page" should be green, then tap Test the microphone.

  4. Install it

  5. Check

    Reload this page. "Secure page" should be green, then tap Test the microphone.

  6. No-certificate shortcut (Android Chrome only)

    Open chrome://flags, search "Insecure origins treated as secure", add , set it to Enabled and relaunch. Then use the http address. Remove it after the demo.

After the hackathon: remove it

iPhone: Settings → General → VPN & Device Management → the mkcert profile → Remove. Android: Encryption & credentials → Trusted credentials → User → remove it. Laptop: run mkcert -uninstall.
